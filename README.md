# Teen-mental-health-dashboard (Excel)

## Project Overview
This project is an interactive Excel dashboard created using the Teen Mental Health dataset.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## KPIs
- Total Records
- Average Stress Level
- Average Anxiety Level
- Average Addiction Level

## Dashboard Features
- Interactive slicers
- KPI cards
- Multiple charts
- User-friendly dashboard

## Dataset
Teen Mental Health Dataset
